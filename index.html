Levar a lista para o Wayground

  1. Baixe o .xlsx (botão ao lado) — ele já vem no template oficial.
  2. No Wayground: Create → Assessment → Start from scratch.
  3. Role a página de tipos de questão até o fim, até Import existing files.
  4. Escolha Spreadsheet → Upload from Device e envie o arquivo.
  5. Revise a prévia, clique Continue e depois Publish.

O gabarito vai na coluna Correct Answer e entra já marcado. As questões da UEM entram como Checkbox (somatório = múltipla resposta) e as da UEL como Multiple Choice.
